# InternNova – Week 2 Assignment
## Python for AI & Data Handling

### Overview
This repository contains the five tasks completed as part of Week 2 of the InternNova Artificial Intelligence and Python Internship.

The assignment focuses on understanding Python libraries used for numerical computations, dataset handling, data cleaning, data visualization, and basic data analysis.

### Technologies Used
- **Python** – Programming language.
- **Jupyter Notebook** – Writing and executing Python programs.
- **NumPy** – Numerical computations and array operations.
- **Pandas** – Dataset handling and data analysis.
- **Matplotlib** – Data visualization.

---

## Tasks Completed

### Task 1: NumPy Fundamentals
- Created 1D and 2D NumPy arrays.
- Performed array indexing and slicing.
- Explored array shape and dimensions.
- Performed basic mathematical operations.
- Used mean, maximum, minimum, and sum functions.

**Files:**
- `numpy_fundamentals.ipynb`
- `Brief explanation of NumPy.pdf`
- `task1_output.png`

### Task 2: Pandas & Dataset Handling
- Created and explored Pandas DataFrames.
- Loaded CSV datasets.
- Displayed first and last rows.
- Checked dataset dimensions and data types.
- Generated statistical summaries.
- Selected columns and filtered records based on conditions.

**Files:**
- `Pandas_Dataset_Handling.ipynb`
- `student_performance.csv`
- Output screenshots

### Task 3: Data Cleaning
- Identified and counted missing values.
- Filled missing values using median values.
- Identified and removed duplicate records.
- Corrected inappropriate data types.
- Displayed and saved the cleaned dataset.

**Files:**
- `Data_Cleaning.ipynb`
- `Cleaning process.pdf`
- `student_data_before_cleaning.csv`
- `student_data_cleaned.csv`
- Data cleaning output screenshots

### Task 4: Data Visualization
Created four visualizations using Matplotlib:

- **Bar Chart:** Compared marks obtained by students.
- **Line Chart:** Represented variations in student marks.
- **Histogram:** Displayed the distribution of student marks.
- **Scatter Plot:** Examined the relationship between student age and marks.

**Files:**
- `Data_Visualization.ipynb`
- `report.pdf`
- `student_data_cleaned.csv`
- Four graph screenshots and dataset output screenshot

### Task 5: Mini Project – Student Performance Data Analysis

Performed basic data analysis on a student performance dataset.

**Activities:**
- Loaded and explored the dataset using Pandas.
- Identified important columns.
- Handled missing values and removed duplicate records.
- Calculated average, highest, and lowest marks.
- Identified the number of students who passed and failed.
- Created three visualizations to analyze student performance.
- Summarized findings through a project conclusion.

**Files:**
- `Task_5_Student_Performance_Analysis.ipynb`
- `report.pdf`
- `student_data_cleaned.csv`
- `student_performance_analysis.csv`
- Task 5 output and visualization screenshots
